รายวิชา 4123307 Web Application Development

ภาพรวมรายวิชา หัวข้อการเรียนรู้ ตารางเรียน ลงทะเบียนความสนใจ

ภาพรวมรายวิชา

รายวิชานี้มุ่งเน้นให้นักศึกษาเข้าใจหลักการพัฒนาเว็บแอปพลิเคชัน ตั้งแต่พื้นฐาน HTML, CSS และ JavaScript ไปจนถึงการพัฒนาเว็บด้วย React

หัวข้อการเรียนรู้

  • พื้นฐานเว็บแอปพลิเคชัน
  • HTML, CSS และ JavaScript
  • React และ Component-Based Development
  • การเชื่อมต่อ API
  • การพัฒนา Backend และฐานข้อมูล

ตารางหัวข้อการเรียน

สัปดาห์ หัวข้อ กิจกรรม
1 บทนำสู่เว็บแอปพลิเคชัน วิเคราะห์เว็บแอปพลิเคชัน
2 สถาปัตยกรรมเว็บและ HTTP ตรวจสอบ Network Request
3 HTML, CSS และ JavaScript สร้างเว็บเพจพื้นฐาน
4 React พื้นฐาน สร้าง Component แรก
5 การจัดการ State ทำระบบตะกร้าสินค้าจำลอง

แบบฟอร์มลงทะเบียนความสนใจ

เครื่องมือที่ใช้ในการเรียน

  • Visual Studio Code
  • Google Chrome DevTools
  • Node.js & Git
